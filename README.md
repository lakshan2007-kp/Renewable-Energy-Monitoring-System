## Project Description

This project focuses on monitoring renewable energy sources in a microgrid. It uses an ESP32 microcontroller and sensors to monitor solar and wind energy generation, battery status, and output parameters.

The system measures voltage, current, and power to help monitor energy generation and consumption. It also provides real-time monitoring through the Blynk IoT platform.
